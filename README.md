## 🔑 Dynamic API Key Manager (`/api` & `/newapi`)

**Unlimited API key support — add as many as you want!**

Inside the CLI prompt (`➜ UNIFIED >`), type:

```bash
/api
```

This opens the **Interactive Dynamic API Key Manager**:

```
🔑 ================= DYNAMIC API KEY MANAGER ================= 🔑
 Choose API Provider to Add (Supports 1 to 1000+ API keys):
 1. 🤖 Gemini API Key  (Direct Google Gemini AI key — FREE tier available)
 2. ⚡ Groq API Key    (Groq Cloud Llama / GPT — FREE tier, ultra fast!)
 3. 🌸 Agnes AI Key    (Agnes API Hub — FREE tier available)
 4. 🔧 Custom Entry    (format: provider:key:model:url — ANY OpenAI-compatible)
 5. 📋 List Status     (Check active API key count)
 0. ❌ Exit / Done
 -------------------------------------------------------------
➜ Select Option (0-5):
```

### Quick Inline Commands:
```bash
/api gemini YOUR_AIzaSy_KEY_HERE        # Add Google Gemini key
/api groq YOUR_gsk_KEY_HERE             # Add Groq Cloud key
/api agnes YOUR_sk-_KEY_HERE            # Add Agnes AI key
/listapi                                # Show all active key counts
/statusapi                              # Same as /listapi
```

## 🔒 Code Protection & Encryption

Source code is protected using **Multi-Layer Bytecode XOR Cipher Encryption**:

1. 🔧 **Compilation** → Source compiled to Python bytecode (`marshal`)
2. 🗜️ **Compression** → Zlib Level-9 maximum compression
3. 🔐 **XOR Cipher** → Multi-round XOR key transformation
4. 📦 **Base64 Payload** → Dynamic in-memory decryption at runtime

> Source code cannot be reverse-engineered or copied directly.
