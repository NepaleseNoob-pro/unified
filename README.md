## ⚡ Super-Fast Offline Spatial Vision OCR (New in v5.0)

UNIFIED v5.0 introduces **Priority 1 Fast Offline Spatial Vision OCR**:

- 🏎️ **Super-Fast Execution**: Processes high-res 3.8MB camera photos in **2.76 seconds** 100% offline!
- 📦 **Local Object Detection**: OpenCV DNN (YOLOv4-tiny) detects cars, scooters, dogs, persons, and signs without any API calls.
- 🔤 **Local Text OCR**: PyTesseract extracts multi-lingual text (English, Hindi, Nepali).
- 🖼️ **Auto Image Resizing**: Automatically scales camera photos (>1280px) for maximum processing speed.
- 🌐 **Cloud Fallback**: Secondary Gemini Vision API fallback for high-detail spatial grounding.

---

## 🤖 Vision-Guided Browser Automation (New in v5.0)

Break free from fragile CSS selectors or obfuscated class names (`class="x912_btn"`):

1. 📸 **Screenshot Page**: Playwright captures page screenshot.
2. 📍 **Spatial OCR Grounding**: `spatial_image_ocr("screen.png")` locates target text/button bounding boxes `[X, Y, W, H]`.
3. 🎯 **Pixel Coordinates Click**: Computes center point `(X + W/2, Y + H/2)` and auto-clicks: `page.mouse.click(cx, cy)`.

## 🔒 Code Protection & Encryption

Source code is protected using **Multi-Layer Bytecode XOR Cipher Encryption**:

1. 🔧 **Compilation** → Source compiled to Python bytecode (`marshal`)
2. 🗜️ **Compression** → Zlib Level-9 maximum compression
3. 🔐 **XOR Cipher** → Multi-round XOR key transformation (`RUPESH_MAHATO_UNIFIED_PROTECTED_KEY_2026_NEPAL_VIPERP`)
4. 📦 **Base64 Payload** → Dynamic in-memory decryption at runtime
